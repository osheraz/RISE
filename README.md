# RISE

**Test-Time Motion Steering for Perceptive Humanoid Fall Recovery**

Osher Azulay\*, Cheng-Lin Hsieh\*, and Stella X. Yu

University of Michigan, Ann Arbor

\*Equal contribution

[Project page](https://osheraz.github.io/RISE/)

RISE introduces perceptive recovery via intent steering. The visual planner steers predicted body states toward task objectives, then generates motion latents for feedback execution.

This repository hosts the project website and demonstration media. GitHub Pages publishes the `main` branch from the repository root.

For a local preview, run `python -m http.server 8000` from this directory.
